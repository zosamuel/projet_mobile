# 📱 Projet Mobile - Programmes Éducatifs

## 📝 Description
Application mobile de **gestion et affichage des programmes éducatifs** développée avec Flutter. Elle permet aux utilisateurs de consulter et gérer les programmes éducatifs avec une interface moderne et intuitive.

## ✨ Fonctionnalités principales

- 🔐 **Authentification utilisateur** : Connexion / Inscription sécurisée
- 📚 **Affichage des programmes** : Consultation des programmes éducatifs
- 📊 **Gestion des cours** : Ajout, modification et suppression
- 📱 **Interface responsive** : Adaptée à tous les écrans mobiles
- 🔄 **API REST** : Communication avec le backend

## 🛠️ Technologies utilisées

| Technologie | Utilisation |
|-------------|-------------|
| **Flutter** | Framework mobile (Dart) |
| **Dart** | Langage de programmation |
| **API REST** | Communication backend |
| **Git** | Versionnement |

## 🚀 Installation

### Prérequis
- Flutter SDK installé
- Android Studio / VS Code

### Étapes

1. **Cloner le dépôt**
   ```bash
   git clone https://github.com/zosamuel/projet_mobile.git
   ```

2. **Installer les dépendances**
   ```bash
   flutter pub get
   ```

3. **Lancer l'application**
   ```bash
   flutter run
   ```

## 📱 Compatibilité
- Android : 5.0+
- iOS : 12.0+ (si configuré)
